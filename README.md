## Tecnologías

* **Arquitectura:** MVC (Modelo-Vista-Controlador)
* **DB:** MySQL

## Instalación
1. Clonar el repositorio.
2. Importar la base de datos `reserva_aulas_cerete`.
3. Configurar `src/java/modelado/Database.java` con tus credenciales de MySQL.
4. Si dentro de `web` no ven la carperta `WEB-INF` deben crearla (Netbeans arroja error si no encuentra dicha carpeta).
5. Ejecutar, click derecho sobre la raíz del proyecto y elegir la opción Run.
