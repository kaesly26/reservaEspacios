## Tecnologías

* **IDE:** NetBeans 8.1

* **Arquitectura:** MVC (Modelo-Vista-Controlador)
* **DB:** MySQL

## Instalación
1. Clonar el repositorio.
2. Importar la base de datos `reserva_aulas_cerete`.
3. Configurar `Conexion.java` con tus credenciales de MySQL.
4. Ejecutar `ReservacionEspacios.java` desde el paquete main.
